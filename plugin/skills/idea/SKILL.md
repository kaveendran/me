# Quick idea

1. Take the idea from `$ARGUMENTS`. If it's empty, ask for it in one short line.
2. Keep the user's framing. Tighten it into one or two sentences only if the dictation rambles, and keep every specific detail.
3. Save it: `me idea "<idea>"`.
4. Reply in one line. Don't evaluate or expand the idea unless the user asks.
